### Restaurant Order & Inventory Management System

Progress
- Menu: active item lifecycle with add, price update, view, and deactivate; price validation and timestamps.
- Sales & Billing: entry validation, item lookup against active menu, bill generation with subtotal and void handling.
- Inventory: stock receive/issue tracking with 3day usage averaging and 2day safety reorder threshold.
- TUI: role-based console flows (manager, salesclerk, inventory staff) using in-memory models; no DB used yet.
